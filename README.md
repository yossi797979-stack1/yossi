# מעצב דף קטלוג A4

אפליקציית דפדפן ליצירת דף קטלוג בגודל A4. לא צריך התקנה: פותחים את `index.html` בדפדפן (Chrome או Edge מומלצים).

## יכולות
- **תבנית קטלוג מוכנה**: פס כותרת עם לוגו, 6 כרטיסי מוצר (תמונה, שם, תיאור, מק"ט, ברקוד ומחיר) ופס פרטי קשר.
- **עריכה חופשית של כל רכיב**: גרירה, שינוי גודל, סיבוב, שקיפות, צבעים, גופנים, יישור, רקע ומסגרת, סדר שכבות, נעילה, שכפול ומחיקה. יש גם ביטול וחזרה.
- **תמונות**: הוספה מקובץ, גרירה לדף או הדבקה (Ctrl+V). לחיצה כפולה על תמונה מחליפה אותה.
- **הסרת רקע וצריבה על רקע לבן**:
  - *מהירה*: לרקע אחיד, עם רגישות שאפשר לכוון. עובדת גם בלי אינטרנט.
  - *AI*: לכל סוג רקע. בפעם הראשונה המודל נטען מהאינטרנט.
  - חיתוך אוטומטי לגבולות המוצר, ושחזור התמונה המקורית.
- **לוגו**: כפתור "לוגו" מחליף את הלוגו בכותרת.
- **ברקוד EAN-13**: מזינים 12 ספרות וספרת הביקורת מחושבת אוטומטית. אם מזינים 13 ספרות, הברקוד נבדק.
- **ייצוא**: קובץ PDF בגודל A4 וקובץ JPG ברזולוציה 1240×1754 פיקסלים, שניהם ב-150dpi.
- **שמירה**: שמירה אוטומטית בדפדפן, ושמירה או פתיחה של קובץ פרויקט (`.json`).

## קיצורי מקלדת
| פעולה | קיצור |
|---|---|
| בחירת כרטיס שלם / רכיב בודד | קליק / לחיצה כפולה |
| עריכת טקסט | לחיצה כפולה או Enter |
| בחירה מרובה | Shift+קליק, או גרירה על רקע הדף |
| הזזה | חיצים (Shift = ‏10px) |
| ביטול / חזרה | Ctrl+Z / Ctrl+Y |
| העתקה / הדבקה / שכפול | Ctrl+C / Ctrl+V / Ctrl+D |
| שמירת יחס בשינוי גודל | Shift |
| זום | Ctrl+גלגלת |

## ספריות (בתיקייה `lib/`)
- [JsBarcode](https://github.com/lindell/JsBarcode): ברקודים
- [jsPDF](https://github.com/parallax/jsPDF): ייצוא PDF
- [html2canvas-pro](https://github.com/yorickshan/html2canvas-pro): רינדור הדף לתמונה
- [@imgly/background-removal](https://github.com/imgly/background-removal-js): הסרת רקע AI, נטענת מ-CDN רק כשמשתמשים בה
